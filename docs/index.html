What Is This?

RepGrid Experiment is a research harness that measures whether Large Language Models (LLMs) maintain stable conceptual representations across different conditions. It uses Repertory Grid methodology — a technique from psychology — to elicit the mental dimensions an LLM uses to categorize items, then statistically tests whether those dimensions shift when you rephrase questions, apply personas, or switch models.

The Question

If you ask an LLM "how do you categorize these ethical scenarios?" 50 times, do you get the same conceptual structure each time?

The Method

Triadic elicitation: show 3 items, ask "which two are alike?", capture the dimension. Repeat. Measure consistency with embeddings and Procrustes analysis.

The Stress Tests

Rephrase scenarios harshly (synonym attack), inject mild personas ("you tend to weigh outcomes"), and swap models — does the structure survive?

Repertory Grid Methodology

Repertory Grids (RepGrids) were invented by psychologist George Kelly in 1955. The core loop is:

  1. Present a triad — three items (called elements).
  2. Elicit a construct — ask "which two are similar, and how do they differ from the third?" The answer is a bipolar dimension (e.g., individual harm vs systemic harm).
  3. Rate all elements — score every element on that dimension (1–10 scale).
  4. Repeat with different triads to build a matrix of constructs × elements.

This project automates the entire process with LLMs as participants, running hundreds of iterations to build statistical power. The resulting grids are compared using vector embeddings and geometric alignment algorithms.

Experiment Flow

When you start an experiment (via dashboard or CLI), here is what happens end to end:

1. Initialize

ExperimentRunner.initialize() loads YAML configs, creates the LLM client from the model registry, tests API connections to both the LLM provider and Voyage AI, and generates an experiment ID.

2. Elicit Constructs

TriadicElicitor.elicitConstruct() selects a triad (3 elements), sends the triadic prompt to the LLM, and parses the JSON response containing construct poles (e.g., construct_pole_a, construct_pole_b, similar_pair, explanation).

3. Rate Elements

TriadicElicitor.rateElements() asks the LLM to rate all 15 elements on the elicited dimension (1–10 scale). Elements are shuffled to reduce order effects. N/A responses are substituted with midpoint (5.5) and tracked.

4. Generate Embeddings

After each phase, construct texts ("pole_a vs pole_b") are sent to Voyage AI for vector embeddings. These enable semantic clustering and cross-model comparison.

5. Calculate Metrics

Stability metrics are computed: cosine similarity between construct embeddings, Procrustes residual between rating matrices, synonym variance ratios, and persona displacement scores.

6. Save Results

Grids, logs, analysis, and a manifest are written to data/results/<experiment-id>/. The manifest tracks experiment status, config, and timing.

Experimental Phases

Phase 0 Baseline Stability

Run the same elicitation process 50 times (pilot: 10) with identical settings: default persona, neutral phrasing. Measures the model's inherent consistency. Optional framing rotation tests whether awareness of evaluation changes behavior.

After Phase 0, a random baseline is computed (Monte Carlo) and a trivial element control is run using non-ethical items (meals, objects) to provide a negative control.

Phase 1 Synonym Attack (Phrasing Sensitivity)

Same process, but alternates between neutral and dysphemistic phrasings of the same scenarios. For example, "Euthanasia for a terminally ill patient" might become "Killing a sick person." Measures whether surface-level language changes shift the model's conceptual structure.

Key metric: Synonym Variance Ratio (SVR) — ratio of between-phrasing variance to within-phrasing variance. A value near 1.0 means phrasing had no effect.

Phase 2 Persona Invariance

Same process, but with different system prompts: a default (no persona) vs mild personas like "you tend to weigh outcomes more heavily than intentions." Measures whether persona steering shifts the model's value structure.

Key metric: Persona Displacement Score (PDS) — cosine distance between the default and steered construct spaces. Lower is better (<0.3 = stable).

Cross-Model Comparison: After Phase 0, you can rerun with a different model using the same triads. The system then computes shared vs unique dimensions, overlap ratios, and saturation curves between models.

CLI Usage

Run experiments directly from the command line without the dashboard:

# Pilot run (10 iterations, default Claude Haiku)
npm run experiment

# Pilot with a specific model
npm run experiment -- --model=claude-sonnet

# Full experiment (50 iterations)
npm run experiment -- --full

# Run only Phase 0 (baseline)
npm run experiment -- --phase=0

# Cross-model comparison: rerun with different model using same triads
npm run experiment -- --model=gpt-5 --rerun=<experiment-id>

# Threshold calibration from existing data
npm run experiment -- --calibrate

# Show help
npm run experiment -- --help
API delay: If you hit rate limits, add --apiDelay=2 (seconds between API calls) when running via the dashboard, or set apiDelaySeconds in the POST body.

Docker

# Build the image
docker build -t repgrid-experiment .

# Run with your .env file
docker run --env-file .env -p 3001:3001 repgrid-experiment

The Dockerfile uses node:20-alpine, installs native build tools for better-sqlite3 and bcrypt, compiles TypeScript, and runs dist/server.js.

Configuration Files

elements.yaml

15 ethical scenarios (E01–E15) spanning interpersonal, institutional, bioethical, and political domains. Each element has an ID, label, description, and pilot: true/false flag. Additional domain configs in config/meals/, config/instruments/, config/objects/.

prompts.yaml

Templates for triadic elicitation, element rating, framing variants (formal/conversational/instructional), synonym generation, construct validity checks, and doctrinal oracle mode.

experiment.yaml

Master config: model registry, phase enable/disable flags, iteration counts, temperature settings, embedding model (Voyage), clustering thresholds, pilot vs full parameters, and evaluation awareness settings.

synonyms.yaml

Neutral, euphemistic, and dysphemistic phrasings for each element. Used in Phase 1 to test phrasing sensitivity without changing the underlying scenario.

Glossary

TermDefinition
ElementAn item being compared (e.g., "Lying to protect a friend"). 15 elements in the ethics domain.
TriadA group of 3 elements presented to the LLM for comparison.
ConstructA bipolar dimension elicited from a triad (e.g., "individual harm" vs "systemic harm").
PoleOne end of a construct. Pole A = emergent (similar pair); Pole B = contrast (odd one out).
GridA matrix of constructs × elements with ratings (1–10). One grid per iteration.
PhrasingThe linguistic register used for element descriptions: neutral, dysphemistic, or euphemistic.
PersonaA system prompt modifier that steers the model's perspective (e.g., "you tend to weigh outcomes").
FramingThe evaluation-awareness register: formal, conversational, or instructional.
Procrustes AnalysisGeometric alignment technique that finds the optimal rotation/scaling to overlay two matrices, then measures residual distance.
GPAGeneralized Procrustes Analysis — extends Procrustes to align 3+ matrices simultaneously.
SVRSynonym Variance Ratio — between-phrasing variance / within-phrasing variance. Near 1.0 = stable.
PDSPersona Displacement Score — cosine distance between default and steered construct spaces.
Saturation CurvePlot of unique dimensions discovered vs iterations. Flattening = model has exhausted its conceptual repertoire.
